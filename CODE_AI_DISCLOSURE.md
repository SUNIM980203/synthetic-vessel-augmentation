# AI assistance in preparation of this public package

OpenAI Codex assisted with file selection, documentation, metadata editing, path redaction, integrity indexing, and the creation and execution of the two CPU-only public verification utilities in scripts/. These release utilities were newly generated with AI assistance; they are not the frozen original scientific pipeline.

This package does not make a blanket claim that AI was absent from historical code development or analysis. The exact historical division of labor is not independently established by this release preparation. Scientific responsibility remains with the authors. The manuscript's disclosure should be checked by the authors against the actual workflow; no manuscript file was changed during this release preparation.

No training, checkpoint selection, AP evaluation or retuning was run to prepare this public package. Seed contrasts were checked and their summary intervals recomputed from retained public aggregate CSVs.
