m의 비정상 손실과 보고서 사후 조정 경위는 숨기지 않고 보존했습니다.

## 연구 질문과 해석

고정된 합성 선박 삽입의 효과가 동일한 학습률에서 헤드 학습과 전체 학습에 따라 달라지는지 비교함. n/s/m 각각 8개 조건 × 10개 짝지은 시드로 80회 수행함. 주 지표는 단순 AP 향상이 아니라 두 학습 범위 사이의 증강 효과 차이임. n은 시드 기준 양의 상호작용이 확인됐으나 장면 재표집에 민감하며, s/m은 불확실함. s의 네 조건별 평균 증강 효과는 모두 음수임. m의 주 분석은 비유한 검증 손실 이력이 있는 영향력 큰 실행을 포함한 10개 시드를 유지하며, 시드 제외 결과는 별도 사후 진단임.

공개 패키지는 무결성 검사와 시드 요약 재계산을 지원하며 전체 학습·독립 AP 평가·장면 재표집 재현을 지원하지 않음. 수정된 배포 파일 `synthetic-vessel-augmentation-v49.4.2.zip`을 이용해야 하며, 태그 기반 GitHub 자동 Source code 압축파일과 구분해야 함.
