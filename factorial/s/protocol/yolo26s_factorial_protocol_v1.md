# YOLO26s factorial protocol v1

Frozen before any factorial result: **yes**.

## Question and hypothesis

Does the positive YOLO26n Unity × adaptation-scope interaction persist in YOLO26s? The designated positive criterion is an xView-test vessel AP50–95 Marginal DiD whose two-sided Student-t 95% CI lies entirely above zero.

## Design

Duplicate/Unity Medium150 × semantic head-only/full-network × LR 1e-4/2e-4 × seeds 20260723–20260732. All 80 fresh cells start from the one locked xView YOLO26s checkpoint, use batch 16, AdamW, 20 epochs, deterministic mode, and epoch-20 `last.pt`.

## Schedule and evaluation

Execution is blocked by seed and randomized within seed using RNG 20260824. Evaluation order is xView test, HRSC2016-MS, DIOR. Full-precision per-image predictions are retained.

## Boundaries

This is a prospectively frozen within-study model-size replication on previously used evaluation sets, not independent or globally untouched confirmation. No manuscript edit, YOLO26m, support High/Low, dose response, new LR, or post-result retuning is authorized.
